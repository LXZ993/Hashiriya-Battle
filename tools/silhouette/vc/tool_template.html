So geht's: Gegner links wählen, Teile rechts ändern. Ausgegraute Teile passen nicht zur Figur (zum Beispiel keine Cap zum Anzug, Feldmütze nur zur Feldjacke, Brille im Haar nur ohne Kopfbedeckung). Geänderte Gegner haben einen orangen Punkt. Deine Änderungen bleiben im Browser gespeichert.

Fertig? silhouetten.json speichern klicken und die Datei nach tools\silhouette\silhouetten.json legen (oder Claude schicken). Dann python tools/silhouette/vc/rivals_v2.py erzeugt die Spielbilder genau so, wie du sie hier siehst.
